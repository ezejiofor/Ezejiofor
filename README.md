## About

I build Kubernetes platforms that are secure by default and observable end to end, then write up exactly how.

My lab is a production-style RKE2 platform on three Proxmox hosts, run entirely through GitOps. It carries a signed CI/CD supply chain, single sign-on for every tool, a lakehouse with role-based access for people and workloads, and a daily ML pipeline that ships models through automated canary releases. Everything is in Git, and every build gets an article.

**What I'm hands on with right now**

* Kubeflow, KServe and automated canary releases for ML models
* Lakehouse security: Trino, Nessie and Iceberg with RBAC for people and machine-to-machine workloads
* Supply-chain security: Tekton, Cosign and Kyverno admission control
* Runtime security and compliance: Falco, Wazuh and open-source SOC 2 mapping
